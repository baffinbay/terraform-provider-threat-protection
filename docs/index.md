# Baffin Bay Threat Protection Provider

The Baffin Bay Threat Protection provider is used to interact with the Baffin Bay API.
It authenticates using the OIDC `client_credentials` grant; access tokens are
cached on disk and refreshed automatically.

## Example Usage

```terraform
provider "baffinbay" {
  # Credentials are read from BAFFINBAY_CLIENT_ID / BAFFINBAY_CLIENT_SECRET
  # environment variables by default. They can also be set explicitly:
  # client_id     = "your-oidc-client-id"
  # client_secret = "your-oidc-client-secret"
}
```

## Token cache

Minted tokens are persisted to `os.UserConfigDir()/baffinbay/token-cache-<hash>.json`
(e.g. `$XDG_CONFIG_HOME/baffinbay/...` on Linux). Override the path with the
`BAFFINBAY_TOKEN_CACHE` environment variable (must be an absolute path). The
cache file is written at mode `0600`; concurrent invocations coordinate via
`flock` so matrix CI jobs share a single mint per expiry window.
