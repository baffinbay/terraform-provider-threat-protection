# Baffin Bay Threat Protection Provider

The Baffin Bay Threat Protection provider is used to interact with the Baffin Bay API.
It authenticates using the OIDC `client_credentials` grant; access tokens are
cached on disk and refreshed automatically.

## Example Usage

```terraform
provider "baffinbay" {
  # Credentials can be provided inline or via the BAFFINBAY_CLIENT_ID /
  # BAFFINBAY_CLIENT_SECRET environment variables.
  client_id     = var.baffinbay_client_id
  client_secret = var.baffinbay_client_secret
}
```

## Token cache

Minted tokens are persisted to `os.UserConfigDir()/baffinbay/token-cache-<hash>.json`
(e.g. `$XDG_CONFIG_HOME/baffinbay/...` on Linux). Override the path with the
`BAFFINBAY_TOKEN_CACHE` environment variable. The cache file is written at mode
`0600`; concurrent invocations coordinate via `flock` so matrix CI jobs share a
single mint per expiry window.
